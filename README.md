# Falling-squares_game-using-pygame

Project Overview:
-->Dodge the falling blue squares and survive as long as you can!
1. You control the red square 🟥
2. Blue squares 🟦 fall randomly from the top
3. Game Over occurs if a blue square touches your red square
Built with Python and Pygame, this game demonstrates collision detection, random movement, and basic game mechanics.

Technologies Used:
1. Python 🐍
2. Pygame 🎮
